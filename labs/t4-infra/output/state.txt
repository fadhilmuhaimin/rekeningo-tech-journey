# --- B. Secret tidak melewati OpenTofu: konfigurasi hanya menyimpan alamat dan path secret manager; nilainya ditulis operator ke OpenBao dan dibaca service saat runtime ---

$ curl -X POST $BAO/v1/secret/data/pembayaran/webhook -H 'X-Vault-Token: <token operator>' -d '{"data": {"sekarang": "<rahasia webhook>"}}'
$ tofu apply -auto-approve

# Yang ada di state: alamat OpenBao dan path secret. Nilainya hanya ada di OpenBao, dan service membacanya sendiri saat berjalan (bagian rotasi.txt).
# Batasnya sempit: ini berlaku karena TIDAK ADA resource atau data source di konfigurasi yang menyentuh nilainya. Bagian C menunjukkan cara paling mudah melanggarnya.
