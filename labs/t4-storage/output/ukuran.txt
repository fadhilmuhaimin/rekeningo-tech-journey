# --- D. Hitungan 28 hari (Asumsi naskah: 2.000 unggahan per hari, 500 KB per file, 43,8 juta posting per tahun x 250 byte) ---
file per hari   = 2.000 x 500 KB               = 1,00 GB
file 28 hari    = 28 x 1,00 GB               = 28,00 GB
posting 28 hari = 43,8 juta / 365 x 28 x 250 B = 0,84 GB
bagian file di bytea = 28,00 / (28,00 + 0,84) = 97,1%
baris verifikasi bila file di penyimpanan objek: 28 x 1.000 x 400 B = 11 MB; bagian baris di data yang dicadangkan = 1,3%
