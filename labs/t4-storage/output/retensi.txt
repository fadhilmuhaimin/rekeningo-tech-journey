# --- B. Job retensi dengan jam diperankan: 29 hari, satu detik sebelum batas, dan (di bagian D) tepat di batas dan 31 hari ---
# Ketiganya selesai berjarak beberapa detik: batas A lebih awal daripada B, B daripada C. Yang diperiksa terhadap satu detik adalah batas A.
$ ./api-t4 -retensi-identitas -lab-sekarang <selesai A + 29 hari>
retensi identitas: diperiksa 0, dihapus 0, galat 0
$ ./api-t4 -retensi-identitas -lab-sekarang <batas A - 1 detik>

file A sesudah kedua putaran itu: masih ada (HEAD)

# --- C. Penyimpanan mati saat job jalan: galat dihitung, baris tidak ditandai, file tetap diulang pada putaran berikutnya ---
$ ./api-t4 -retensi-identitas -lab-sekarang <batas A>
retensi identitas: diperiksa 1, dihapus 0, galat 1
baris A sesudah putaran gagal: kunci objek masih terisi (belum ditandai terhapus)

# --- D. Penyimpanan pulih: tepat di batas dihapus (hapus_pada <= sekarang); diulang tidak mengubah apa pun; pengajuan lain menunggu batasnya ---
$ ./api-t4 -retensi-identitas -lab-sekarang <batas A>
retensi identitas: diperiksa 1, dihapus 1, galat 0
file A (HEAD): kartu tidak ada, swafoto tidak ada
$ ./api-t4 -retensi-identitas -lab-sekarang <batas A>
retensi identitas: diperiksa 0, dihapus 0, galat 0
