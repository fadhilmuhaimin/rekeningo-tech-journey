# --- A. Hitungan naskah (Hitungan atas Asumsi): pengirim serentak untuk notifikasi uang makan siang ---
lambda makan siang = 650.000 x 0,8 / 5.400 = 96,296 -> 96,3 per detik
L = lambda x t = 96,3 x 0,3 = 28,89 -> 29 pengirim serentak (naskah menulis 28,9 lalu 29)
8 proses x 4 = 32 pengirim -> kapasitas 32 / 0,3 = 106,7 per detik, terpakai 96,3 / 106,7 = 90,3%
11 proses x 4 = 44 pengirim -> kapasitas 44 / 0,3 = 146,7 per detik, terpakai 96,3 / 146,7 = 65,7%
proses minimal = ceil(28,9 / 4) = 8; untuk terpakai paling tinggi 70%: ceil(28,9 / 0,7 / 4) = 11

Pengumuman ke 1.000.000 perangkat dalam 30 menit (Hitungan atas Asumsi)
laju = 1.000.000 / 1.800 detik = 555,6 per detik
pengirim = 555,6 x 0,3 = 166,7 -> 167
consumer = ceil(167 / 4) = 42; partisi paling sedikit = 42 (satu partisi dibaca satu consumer dalam satu grup)
kuota penyedia: 555,6 / 10.000 = 5,6% dari kuota; semua dalam semenit: 1.000.000 / 60 = 16.667 per detik = 167% kuota
uang + pengumuman = 75,2 + 555,6 = 630,8 per detik selama 30 menit
breaker per proses: 6 kegagalan x 11 proses = 66 kegagalan sebelum semua breaker terbuka
