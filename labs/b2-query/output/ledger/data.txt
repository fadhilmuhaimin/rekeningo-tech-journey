# --- A. Asal angka ---
Naskah (plan/CERITA-TAHAP-2.md): 1.000 karyawan, 12 warung, top-up tiap Senin, pencairan tiap Jumat,
  transaksi per hari = 1.000 user x 30% aktif x 3 = 900 (bagian Pertumbuhan skala).
Data lab (labs/b2-query/ledger_data.py, random.Random(15)): 364 hari mulai Senin 2025-10-06,
  top-up Rp250.000 per karyawan, 85% bayar ke warung dan 15% kiriman antar karyawan,
  Warung Ani dipilih 3x lebih sering dari warung lain, Budi membayar 6x lebih sering dan menerima
  kiriman patungan 40x lebih sering dari karyawan lain. Pembayar dipilih ulang bila saldonya kurang.

# --- C. Statistik planner dari seluruh baris, autovacuum dimatikan di tabel lab ---
=> ALTER TABLE jurnal SET (autovacuum_enabled = false);
=> ALTER TABLE posting SET (autovacuum_enabled = false);
=> SET default_statistics_target = 10000;
=> VACUUM (ANALYZE) akun, buku, jurnal, posting;
ANALYZE mengambil sampel 300 x statistics target baris; 3.000.000 > 760.448, jadi semua baris dibaca dan
rencana sama di setiap rekaman. Autovacuum tidak boleh menimpa statistik ini di tengah lab (keputusan 523).
