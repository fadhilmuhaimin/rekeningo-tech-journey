# `breaking` hanya memuat ERR dan WARN; field opsional yang dihapus berstatus INFO. Klien lama yang membaca
# field itu tidak ditahan gerbang. Tingkat bisa dinaikkan dengan berkas --severity-levels:
$ cat tingkat.txt
response-optional-property-removed err
$ oasdiff breaking sebelum.yaml field-opsional-hapus.yaml --severity-levels tingkat.txt --fail-on ERR
1 changes: 1 error, 0 warning, 0 info
error	[response-optional-property-removed] at field-opsional-hapus.yaml
	in API GET /akun/{id}
		removed the optional property `nomor_karyawan` from the response with the `200` status
(exit code 1)
