# Lab t4-audit · jangkar harian di luar database: ekor dipotong, rantai ditulis ulang, dan batas jangkar
# PostgreSQL 17.11 (Debian 17.11-1.pgdg13+2) · go1.27.1 · pgx v5.11.0 · schema tahap4_audit · server Go di 127.0.0.1:18280
# Rekaman dari database bersih: make -C labs/t4-audit run.
# server: ./api-t4 -lab; jangkar harian: ./auditjob sebagai role t4a_verifikator (hanya SELECT) dan berkas di folder di luar database

# --- A. Jangkar harian: hari 1 (baris 1 sampai 4), hari 2 (baris 5 dan 6), hari 3 belum dijangkarkan (baris 7 dan 8) ---
# Berkas jangkar ada di folder sementara di luar database; tidak ada role database yang menyentuhnya. Hash baris tidak direkam (bergantung pada waktu aksi).
# Hari diperankan: log dipulihkan dari salinan sampai baris tertentu, lalu pemeriksaan dijalankan. Tidak ada jam harian yang berjalan di lab.
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
baris=4 rantai=utuh jangkar_lama=0 temuan=0
jangkar baru: nomor 4
# exit status 0
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
baris=6 rantai=utuh jangkar_lama=1 temuan=0
jangkar baru: nomor 6
# exit status 0
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
baris=6 rantai=utuh jangkar_lama=2 temuan=0
# exit status 0
# Dijalankan lagi tanpa baris baru: tidak ada jangkar baru.
# Log penuh: 8 baris. Berkas jangkar: 2 baris (nomor 4 dan 6).

# --- B. Ekor dipotong: baris 5 sampai 8 dihapus oleh pemilik tabel ---
=> [t4a_pemilik] DELETE FROM audit_log WHERE id >= 5
DELETE 4
# Tanpa jangkar luar (berkas jangkar kosong), pemeriksaan harian tidak punya pembanding:
$ ./auditjob -db <role t4a_verifikator> -jangkar kosong.jsonl
baris=4 rantai=utuh jangkar_lama=0 temuan=0
jangkar baru: nomor 4
# exit status 0
# Rantai utuh, dan keadaan yang sudah terpotong malah dijangkarkan. Dengan berkas jangkar yang sebenarnya:
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
baris=4 rantai=utuh jangkar_lama=2 temuan=1
jangkar nomor 6: baris-hilang
# exit status 2
# Jangkar nomor 4 masih cocok, nomor 6 hilang bersama ekornya: satu temuan, dan keadaan yang rusak tidak dijangkarkan.

# --- C. Baris tengah ditulis ulang dan rantainya dihitung ulang sampai ujung oleh pemilik tabel ---
# Baris 2 diganti pelakunya, lalu hash baris 2 sampai 8 dihitung ulang dengan rumus yang sama (skrip lab).
$ ./auditjob -db <role t4a_verifikator> -jangkar kosong.jsonl
baris=8 rantai=utuh jangkar_lama=0 temuan=0
jangkar baru: nomor 8
# exit status 0
# Tanpa jangkar: rantai utuh, dan baris yang sudah ditulis ulang dijangkarkan. Dengan berkas jangkar yang sebenarnya:
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
baris=8 rantai=utuh jangkar_lama=2 temuan=2
jangkar nomor 4: hash-beda
jangkar nomor 6: hash-beda
# exit status 2

# --- D. Perubahan sesudah jangkar terakhir (baris 7 dan 8) tidak dicakup jangkar hari 2 ---
=> [t4a_pemilik] DELETE FROM audit_log WHERE id >= 7
DELETE 2
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
baris=6 rantai=utuh jangkar_lama=2 temuan=0
# exit status 0
# Dua baris yang dihapus sebelum jangkar berikutnya tidak terdeteksi. Jangkar hanya menutup yang sudah ada saat jangkar dicatat; jendelanya sampai jangkar berikutnya.
# Jangkar berikutnya akan dicatat dari keadaan yang sudah terpotong: kejadian 7 dan 8 hilang tanpa jejak.

# --- E. Penyerang yang juga menulis berkas jangkar ---
=> [t4a_pemilik] DELETE FROM audit_log WHERE id >= 5
DELETE 4
# Berkas jangkar ikut dipangkas: baris untuk nomor 6 dihapus. Berkas itu ada di luar database, jadi ini butuh hak tulis kedua di tempat jangkar.
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
baris=4 rantai=utuh jangkar_lama=1 temuan=0
# exit status 0
# Pemotongan lolos. Tempat jangkar harus tidak bisa ditulis oleh siapa pun yang bisa menulis log (akun lain, tulis-sekali): Tidak dijalankan di lab.
# Berkas jangkar dihapus seluruhnya:
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
baris=4 rantai=utuh jangkar_lama=0 temuan=0
jangkar baru: nomor 4
# exit status 0
# Berkas yang tidak ada dibaca sebagai 'belum ada jangkar', sama dengan hari pertama: pemeriksaan tidak bisa membedakan keduanya.

# --- F. Berkas jangkar rusak: pemeriksaan gagal, tidak melewatinya ---
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
auditjob: jangkar baris 3: invalid character 'b' looking for beginning of value
# exit status 1
$ ./auditjob -db <role t4a_verifikator> -jangkar jangkar.jsonl
auditjob: jangkar baris 1: nomor atau hash tidak sah
# exit status 1
