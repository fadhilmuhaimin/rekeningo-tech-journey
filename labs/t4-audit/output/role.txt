# --- C. Sisi yang melewati pembatasan: pemilik tabel dan superuser. Hak tabel membatasi aplikasi, bukan mereka ---
=> [t4a_pemilik] UPDATE audit_log SET alasan = 'diubah pemilik tabel' WHERE id = 2

=> [lab] UPDATE audit_log SET alasan = 'diubah superuser' WHERE id = 3
UPDATE 1
=> [lab] DELETE FROM audit_log WHERE id = 5

# Dua baris diubah dan satu dihapus. Hak tabel tidak menghalangi mereka. Yang menangkapnya adalah rantai dan jangkar (bagian rantai dan jangkar):
$ ./auditjob -db <role t4a_verifikator> -jangkar role.jsonl
baris=5 rantai=putus di baris 2 jangkar_lama=0 temuan=0
# exit status 2
# Pemilik tabel boleh mencabut hak dirinya sendiri, tetapi bisa memberikannya lagi:
